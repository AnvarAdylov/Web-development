| Month | Topic | What's inside |
|---|---|---|
| [1](month%201) | HTML, CSS, Bootstrap | 16 static sites (box model, positioning, flexbox, forms, Bootstrap) and the month 1 exam. All run live on the demo page. |

## Running things locally

**Static sites (month 1):** open any `index.html` in a browser.

**Python exercises (months 2–4, 6):**

```bash
python "month 3/exam_3_anvar_adylov/Task1.py"
```

**SQL (month 5):** load `month 5/Lab 2/dump/dump.sql` into PostgreSQL or MySQL and run the task files against it.

**Django (month 6):**

```bash
cd "month 6/Lesson 41/mysite/mysite"
pip install django
python manage.py runserver
```
